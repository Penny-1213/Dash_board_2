3. Comprehensive Company Metrics

本區塊提供逐家公司查詢，將公司基本資訊、風險報酬指標與目前選定期間的預測報酬放在同一張表中，方便交叉比較。
可使用搜尋欄依公司名稱、股票代碼或產業篩選資料。

How to read this section

Expected Return 為資料中提供的預期報酬指標，Volatility 用來描述報酬波動程度，Pred. Return 則會隨上方選定的預測期間更新。建議將這些欄位視為比較與探索的依據，並留意不同指標的計算方式與資料期間是否一致。
